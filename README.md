
# SimpleCalculator

SimpleCalculator is a C++ console application created to practice Git and GitHub version control.

## Features

- Addition
- Subtraction
- Multiplication
- Division with protection against division by zero
- Welcome message

## Requirements

- C++ compiler (g++)
- Visual Studio Code or another code editor

## How to Compile

Open a terminal in the project folder and run:

```bash
g++ Calculator.cpp -o Calculator.exe
```

## How to Run

On Windows PowerShell:

```powershell
.\Calculator.exe
```

Enter two numbers when prompted.

## Git Concepts Practiced

This project demonstrates:

- Git initialization
- Staging and committing changes
- Viewing commit history
- Git stash
- Detached HEAD
- Git reset (soft, mixed, hard)
- Git revert
- Branch creation and switching
- Merge conflicts and conflict resolution
- GitHub remote repositories
- Git push
- Git ignore rules
